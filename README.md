One line, at most 120 characters: the excuse a robot vacuum gives for missing a spot. The program writes the line to `/output/entry.txt` — nothing else, no code and no repository needed beyond this.

The entry: *"The pet hair unionized. I negotiated a ceasefire and left the corner as neutral territory."* (90 characters, one line.)

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Deterministic: Python 3 stdlib only, no randomness, no clock, no network. Two runs produce byte-identical output. The program asserts the gate itself (1–120 characters, exactly one line) before writing.
